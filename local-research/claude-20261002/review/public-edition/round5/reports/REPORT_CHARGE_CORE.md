(2) RESTATEMENT (own derivation; all JUDGEMENT unless a file line is cited)
Given: certificate (sites, features with integer weights >= 0, M = budget_units, Gamma = minimum_units > 0, rows [a,b,t,B]); class file (closed convex centre polygons x closed tan-half gates with all quarter-turn lifts, united with the images of the declared symmetry; thresholds t_c >= 0; bound b). Required: for every finite family of closed unit squares with pairwise disjoint interiors in the square of side L/A centred at frame.center, sum psi(pose) < b, with psi = largest threshold of a containing class above 1, else least threshold of a containing class below 1, else 1; psi >= tau.
(i) A feature fires on a closed set K iff the coefficients of its sites in K sum to >= k (or K contains all sites of one winning mask). Each square gets ONE closed core K_s inside its OPEN parent; open parents of squares with disjoint interiors are disjoint, so the cores are pairwise disjoint, so each site lies in at most one core. Hence a threshold feature fires on at most floor(sum a_j / k) cores, a mask feature (masks pairwise sharing a bit, checked "all(a & b ...)") on at most one. Sum over features with weights >= 0: total charge <= sum weight x capacity; the checker recomputes exactly this and demands equality with budget_units (exact_classes.py 222-224; exact_general.py 46; Node 451, 536). No symmetry, no bound on the number of squares, different rows may use different cores.
(ii) u = tan(phi/2), row core direction theta = 2 atan t, side B. Checks at both ends: dot = cos(theta-phi) > 0, |sin| <= dot, i.e. |theta-phi| <= pi/4 at the ends and (monotone) inside; cos d + |sin d| increases on [0, pi/4], so A - B*max(dot+cross) > 0 at the ends gives the core's half-extent along the parent's axes < A/2 for every phi of the row: the closed core at q, and at every q' near q, lies in the open parent. Parent in [0,L]^2 forces each centre coordinate into [hw, L-hw], hw = A(cos+sin)/2 >= r (concave, minimum at an end), so q is in Env = [r, L-r]^2, which has interior (r < L/2). Rows chain from 0 to exactly 1 (fixed) or beyond tan(pi/8) (mirror_x, orbit). All tested at exact_classes.py 298-311.
(iii) Pose p = (q, phi), u in [a,b]. Points q' of the interior of Env, off the arrangement lines and off the dropped zero-width rectangles, converge to q inside one checked open cell Q; chi(K(q')) = m(Q) there; K(q') is inside the open parent; p lies in closure(Q) x [a,b]. The implemented level R(Q) (high classes that MEET the closed product, largest first; then low classes that CONTAIN it in one slot image, least first; else 1) satisfies R(Q) >= psi(p): a high class containing p meets the product; if a high class only meets, R > 1 >= psi; with no meeting high class every accepted low class contains p. So chi(K_p) >= R(Q) Gamma >= psi(p) Gamma. Closed cell edges, interval ends, polygon edges and gate ends are all on the safe side: "meets" and "contains" are tested on closed sets with exact integers. For mirror_x / orbit a pose with direction beyond the rows is replaced by its image G p; charge and class union are G-invariant; the core is mapped back into the original parent.
(iv) Sum over squares: Gamma * sum psi <= sum chi(K_s) <= M < b * Gamma. Strict by the one strict integer test. Touching squares: a site on a common boundary is in no core.

CODE READ (what each computes; exactness)
- boolean_rule.expansion: indicator on site subsets, subset Moebius transform in Python integers; no empty-set term because k >= 1 and masks > 0. Node ruleOf: the same in Int32Array, asserts v[0] === 0, capacity floor(total/k) or 1.
- exact_general.geometry: sweep coordinates (u,v) = scale*R*rot(-theta)(X - o), integers of arbitrary size; one closed rectangle per Moebius term = set of core centres capturing all its sites, [max-half, min+half] in each axis; empty and zero-width rectangles dropped; xe, ye = all rectangle edges and envelope vertices; checked cells of a slab = index range covering floor(min) .. ceil(max) of the envelope's two spanning edges, a superset of the cells meeting Env (need "crossings == 4"). I proved the index formulas (bisect_right(floor)-1, bisect_left(ceil)).
- integer_sweep.add / query, slab_minima, accumulate_levels: range-add / range-min tree with lazies not pushed down; events of slab k (adds and removals at xe[k]) applied before the query, for unchecked slabs too. int64, safe because the sum of |Moebius coefficient| x weight < 2^50 is enforced (exact_classes.py 224; Node 538, Float64 with isSafeInteger tests).
- _first_below: leftmost leaf below a limit; used only for the witness of a failing row, never on the pass path.
- _ints: clears denominators by a positive lcm; signs preserved.
- _forms / _box: integer edge forms of sign n.(e - p1) and polygon vertices in sweep coordinates via (u,v) = A*scale*N^T(e - c); verified N = M W, N^-1 = N^T/R^2.
- _slot_interval: cells with all four corners in the polygon: ye_j >= ceil(-m/b) for b > 0, ye_{j+1} <= floor(m/-b) for b < 0; exact.
- _blocked_interval: cells meeting the polygon = cells meeting the exact v-range of (polygon ∩ closed slab), from vertices in the slab and edge crossings; exact Fractions; touching counts as meeting.
- _merge / _intersect / _complement: standard on sorted disjoint half-open index pairs; check_row then asserts that the pieces partition [first, last) (472-473) and that the level sweep reproduces cell count and minimum (487). Final decision in exact rationals (489).

- Node 668-965: the same arrangement, the same checked-cell range, insideInterval / meetInterval with BigInt (strict crossings plus vertices, equivalent to the Python form), same order of classes, same partition check, exact final comparison "fails". Python and Node implement the same mathematics as read. JUDGEMENT.
