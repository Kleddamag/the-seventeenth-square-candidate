== 1. The semantics in my own words ==
A class file gives a frame (container centre, here 1169/500 = U/2), a symmetry word (fixed / mirror_x / orbit), a rational bound B, and classes. A class = name, rational threshold t >= 0, and slots; a slot = closed convex polygon of square CENTRES x closed interval of tan(theta/2), read with all quarter-turn lifts; a class is the union of its slots (plus mirror / D4 images if the symmetry word says so). Classes with t > 1 are "high" (the triggers, e.g. half-marker M and the trigger T, t = 4), classes with t < 1 are "low" (the exempt target, t = 0).
The certificate is a charge: integer sites in the container, features (site lists with a threshold rule or intersecting winning masks) with non-negative integer weights, budget_units M, minimum_units Gamma, and 18,000 rows [a, b, t, B_core]: an interval of side directions and a core square (direction t, side B_core) that lies STRICTLY inside every unit square whose direction is in [a, b] and shares its centre.
One checked cell asserts: for every core centre in that closed cell and every direction of the closed row interval, charge >= R x Gamma, where R = largest threshold of a high class that the closed cell x interval MEETS; else least threshold of a low class that CONTAINS the whole closed cell x interval in one slot image; else 1.
Cover: rows are chained (a = previous b, from 0 to u = 1 for "fixed", i.e. directions 0 to 90 degrees = all directions of a square); in each row the slabs and y-cells of the sweep partition the whole envelope of admissible centres; all cell and interval tests are on closed sets, so nothing falls between.
Chain: psi(p) = max high threshold containing p, else min low threshold containing p, else 1. (i) R(cell) >= psi(p) for every pose p in the closed cell x interval. (ii) charge(p) >= Gamma psi(p) (cell check; boundary poses by a limit of generic centres, charge being monotone in the set of captured sites). (iii) DISJOINTNESS: squares have disjoint interiors, cores are strictly inside, so cores are pairwise disjoint, each site is in at most one core; a threshold feature (threshold k, coefficient mass a) fires for at most floor(a/k) squares, a mask feature for at most one; hence sum of charges <= M. (iv) Gamma sum psi <= M. (v) STRICTNESS: integers M q_b < p_b Gamma, i.e. surplus = B Gamma - M > 0 (10 units in the example, 12 for the slab), so sum psi <= M/Gamma < B.
Smaller sides: a packing of side S <= C placed concentrically is a family inside the square of side C; the check is for that one square.
