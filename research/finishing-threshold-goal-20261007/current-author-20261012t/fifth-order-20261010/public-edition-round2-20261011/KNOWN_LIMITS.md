# Scope and retained limitations

The current capture records replace the earlier execution envelopes. The public replay rechecks both engines' saved exact decisions and file/provenance bindings. It does not repeat a geometric sweep or authenticate whether an operating-system execution really occurred. Interpreter/library identity is recorded at the stated level; recursive binary authentication is outside this proof packet.

Historical independent reports retain original reviewed-byte identities and dated mathematical qualifications. Their neutral reading copies do not constitute new reviews of changed checker programs or new executions. The earlier-execution map makes this distinction explicit.

Capture environment variable values were not recorded per attempt. A later reported probe of one machine in the second runtime observed NODE_OPTIONS=--max-old-space-size=8192 (a heap-limit setting); this does not establish the values on every selected attempt. That supplementary observation is reported evidence, not an author-observed execution. Node binaries were identified by version strings, not binary digests. No stronger environment authentication is claimed for either runtime.
