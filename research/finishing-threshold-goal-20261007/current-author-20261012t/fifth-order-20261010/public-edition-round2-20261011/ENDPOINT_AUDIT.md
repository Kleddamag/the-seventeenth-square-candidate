# Endpoint enclosure and every mathematical use in the public proof

The public `endpoint_upper` check contracts the unique root from the radius-10^-12 defining box to radius 10^-50. Its saved `side_interval` is the wider interval. It does not assert containment in `EXACT_ENDPOINT_AND_CASES.json`'s tight interval (coordinate radius 10^-55). This is a real distinction between evidence objects, not a loss of existence or uniqueness.

`check_endpoint_enclosure.py` adapts the Banach construction from check_endpoint.py and proves radius 10^-58 about the same midpoint. Its monotone rational side image is strictly inside **both** the packet's tight L interval and the terminal gate's side interval. Both coordinate intervals are strictly inside **both** imported tight root boxes. `ENDPOINT_ENCLOSURE_CHECK.json` binds the input bytes and lists all intervals exactly. The check uses only standard-library Fraction arithmetic and writes only stdout. It does not import the endpoint or terminal producer. The contraction code adapts the earlier endpoint checker and is not an independent implementation. The integration explicitly checks positive epsilon, denominator positivity throughout the refined interval, both printed wall margins, and equality of the statement polynomials to the certificate. The mathematical receipt is deterministic; execution timing belongs only to the replay runner receipt.

For clarity, if B is the defining box, m its midpoint, A=DF(m)^(-1), q an interval upper bound for the infinity-norm of I-A DF on B, and eta=||A F(m)||_infinity, the exact checks are q<1, eta+q*10^-12<10^-12 and eta/(1-q)<10^-58. The continuous map x -> x-A F(x) therefore maps the complete closed box B into itself and contracts it; its unique fixed point is the unique zero of F there because A is invertible. Its distance to m is at most eta/(1-q). For the side f(t)=(6+4t)/(1+2t-t^2), f'(t)=4(t^2+3t-2)/(1+2t-t^2)^2<0 on the new box. Thus evaluating f at the two rational t endpoints in reverse order is an exact enclosure. No numerical root finder is involved.
